# Mohamed Ibrahim Portfolio

## Project description
A personal portfolio website for Mohamed Ibrahim, a first-year student at NJIT. It shows class projects in Python, skills, education, and contact information. It is built with plain HTML, CSS, and JavaScript only, with no frameworks and no backend.

## Live website
https://theomaribr.github.io/portfolio/

## How to view the website locally
Open index.html by double-clicking it in a file browser, or open the portfolio folder in VS Code and use Live Preview. No server, database, or login is needed.

## Notes
This site was built for the SDET 101 Midterm Project: Portfolio Web Design. All project screenshots are from class work in Google Colab.
