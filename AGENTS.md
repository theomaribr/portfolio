# Portfolio Site

## What this site is
A personal portfolio website for Mohamed Ibrahim, a first-year student at NJIT. It has five pages: Home, About Me, Projects, Skills, and Contact.

## Design
Colors: modern casual theme, light slate background with dark navy text, and a red accent for links, buttons, and headings. Dark navy header with a red bottom border. Dark mode uses a dark navy background with light text and a lighter red accent. Fonts: Arial and Helvetica, for clear reading. Style: rounded cards with a red left border and a soft shadow, clear headings, and no sideways scrolling on phone or laptop screens.

## Rules
Plain HTML, CSS, and JavaScript only. No frameworks, no build tools, no backend, no databases, and no logins. Use one external stylesheet, styles.css. Use relative file paths, such as styles.css and images/assignment1.jpg. Use semantic HTML5 elements, one h1 per page, and headings in order. Give every image alt text. Keep image files under 500 KB. Do not include a phone number, home address, API key, password, or token in this repository.

## Git
Commit after each task with a clear message, then push to GitHub. Work over multiple days, with small commits.
